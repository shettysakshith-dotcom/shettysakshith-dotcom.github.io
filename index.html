01Experimentation

cuped

A CUPED variance-reduction library for A/B tests that refuses covariates measured after randomisation and tests that bias case explicitly. It combines a declared-window check with a balance test across arms.

  • On a 30,000-customer demo, CUPED removed 38.7% of the variance, turning an 11-week test into a 7-week one.
  • A post-treatment covariate removed 98.3% of variance yet returned an effect of -6.601 against a true 1.80; the gate rejects it.
  • Python
  • A/B Testing
  • CUPED
  • Variance Reduction
  • Statistical Testing

02Marketing analytics

mixpriors

A Bayesian media mix model with informative adstock and saturation priors. Its budget optimiser maximises expected return under the posterior and reports a credible interval instead of a single number.

  • In the demo, all 9 of 9 true channel values fall inside their 90% intervals.
  • Scored on the true curves, the posterior-aware plan gained +2.77% while the point-estimate shortcut lost 1.18%.
  • Splits a GBP 45M annual budget across nine channels from 156 weekly observations.
  • Python
  • Bayesian Modeling
  • Metropolis-Hastings
  • Adstock
  • Hill Saturation

03Reliability analytics

uattriage

UAT analytics that fit defect-discovery curves to estimate remaining latent defects and a go-live readiness date with an uncertainty band, instead of reporting raw defect counts.

  • Refuses to project when discovery has not flattened (b*T < 0.7) instead of returning a runaway number.
  • Demo on a simulated UAT project: 807 defects over 45 days, with latent-defect intervals per severity.
  • Calibration tests check interval coverage over 200 runs.
  • Python
  • Goel-Okumoto (NHPP)
  • Kolmogorov-Smirnov test
  • Defect Analytics
  • JavaScript
